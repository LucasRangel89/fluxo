🎬 Fluxo uma sessão guiada de análise audiovisual com IA

Conte a obra uma única vez. O Fluxo monta a jornada inteira — pesquisa, mapa 360°, aprofundamento e síntese — como cartões guiados ou como um Prompt Maestro para uma única conversa.

Não consegui carregar os templates. Esta página lê os arquivos de prompts/ em tempo real e, por isso, precisa ser servida por HTTP. Na raiz do repositório, rode python -m http.server 8000 — ou use a CLI.

⚙️ Executar dentro do Fluxo (opcional)

O projeto não possui chave de IA nem backend. O modo manual é o padrão gratuito. As alternativas abaixo usam a conta, a chave ou o dispositivo do próprio usuário.

Ao executar, o Puter poderá pedir login. O uso é debitado da conta/cota do usuário, não do projeto.
Nunca usamos uma chave do projeto e a chave não entra nas exportações da sessão.

Usa a Prompt API do navegador quando disponível. É mais adequada a resumos e microtarefas do que à análise completa de obras longas.
